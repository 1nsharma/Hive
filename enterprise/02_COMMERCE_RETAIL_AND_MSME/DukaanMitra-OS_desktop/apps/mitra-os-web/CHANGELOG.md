# Changelog: DukaanMitra Platform

> **Status:** ACTIVE
> **Classification:** PUBLIC (Google Indexable)

All notable changes to the DukaanMitra Platform will be documented in this file. This project adheres to Semantic Versioning (`vMAJOR.MINOR.PATCH`).

---

## [3.0.0] - 2026-07-25

### Added
- **Three-Layer Documentation System:** Classified the DukaanMitra Engineering Bible into Public, Developer, and Internal levels.
- **Access Gating & Handshake Simulation:** Added interactive bypass simulations and passcode vaults (`DM-INTERNAL-99`) for Developer and Internal specifications.
- **Enterprise Security Section:** Documented RBAC, ABAC, Single Sign-On (SSO), and dual-control approval mechanisms.

### Changed
- **Header Structure:** Replaced direct model/class labels in public sections with generalized conceptual structures (e.g., "AI Agent Overview", "Prompt Management (Conceptual)").
- **Accessibility Enhancements:** Upgraded color contrast ratios and responsive spacing metrics across all documentation viewports.

---

## [2.0.0] - 2026-06-15

### Added
- **Full-Stack Architecture:** Shifted from client-only architecture to Express + Vite full-stack server configuration.
- **Vite Bundler Optimization:** Implemented `esbuild` server-side compilation outputting to static CommonJS CJS bundles.
- **Multilingual SEO Support:** Automated XML Sitemap generation integrating Hindi, Tamil, Hinglish, and custom FAQ schemas.

---

## [1.0.0] - 2026-01-10

### Added
- **Initial MVP Release:** Core WhatsApp-first billing mechanics, local ledgers, and inventory catalog configurations.
- **Secure payment triggers** using pre-configured Razorpay checkout webhooks.

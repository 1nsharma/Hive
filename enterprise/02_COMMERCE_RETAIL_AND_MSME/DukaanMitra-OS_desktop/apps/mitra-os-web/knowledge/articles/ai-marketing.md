# AI Marketing for Local Businesses

## Definition
Using Artificial Intelligence tools to automate, personalize, and scale marketing efforts for local stores.

## Use Case
DukaanMitra uses AI to send personalized, automated WhatsApp reminders for Udhaar collection in Hinglish.

## Example
"Bhaiya, aapka ₹500 baaki hai, kal chuka dijiyega." generated automatically based on user behavior.

## FAQ
- **Is AI marketing expensive?** With WhatsApp native tools, it's highly cost-effective for local setups.

## Purpose

This document outlines the product roadmap and learning framework built into BazaarSync to empower local developers, accountants, and staff to master modern Web Engineering concepts.

## Content

### 1. Interactive Learning Roadmap (रोडमैप)
We have designed and fully implemented an interactive **Front-end Developer Roadmap** matching industry standards (inspired by roadmap.sh) directly inside the BazaarSync workspace.

- **Interactive Skill Nodes**: Covers Internet basics, HTML/CSS layout concepts, Git version control, package managers, React hook models, Vite build engines, unit testing with Vitest/Jest, CORS web security, and TypeScript types.
- **Progress Tracking & Stats**: Calculates mastery percentages dynamically and persists status (`Todo` 🔲, `Learning` 📖, `Mastered` ✅) in local storage.
- **Bilingual Explanations**: Features precise, easily readable descriptions in both English and Hindi.
- **Core Challenges & Quizzes**: Integrates instant multi-choice concept checks with clear, immediate explanations.
- **Streak Tracker**: Tracks active daily learning streaks with animated flame micro-interactions.

### 2. Integration & Access
- Accessible via the **Quick Actions** section on the main Workspace OS screen.
- Linked inside the **App & Training** settings of the primary dashboard menu.

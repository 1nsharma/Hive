# @aemy/ui-kit

Standardized, highly reusable UI components crafted with React 19 and Tailwind CSS v4.

## Components Included
- **Button**: Multi-variant, accessible button with loading state.
- **Badge**: Status indicators and tag labels.
- **Card, CardHeader, CardTitle, CardContent, CardFooter**: Consistent dark glassmorphic cards.
- **MetricCard**: Analytics metric visualization with KPI trend pill and icon slot.
- **SectionHeader**: Professional section titles with description and action slot.
- **StatusIndicator**: Pulsing live status indicator for autonomous agent activity.

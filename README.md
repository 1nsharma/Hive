## ⚡ Quick Start & Verification

### 1. Interactive Master Launcher
Double-click `START_HIVE_SYSTEM.bat` or run in terminal:
```bash
.\START_HIVE_SYSTEM.bat
```
Menu Options:
- `[1]` Start Web Virtual Office & Dashboard (http://localhost:3300)
- `[2]` Launch Hive Desktop Orchestrator (Electron 32 + Monaco + Pixi.js)
- `[3]` Launch BOTH Web + Desktop App Simultaneously
- `[4]` Run Master System Hub Diagnostics
- `[5]` Run Phyllis's B2B Research Engine CLI
- `[6]` Run Andy's Deal Closing Engine CLI
- `[7]` Deploy / Sync Web App to Vercel Cloud
- `[8]` Run Comprehensive Unit Tests

### 2. Run Diagnostics
```bash
node hive-system-hub.mjs
```

### 3. Run Automated Tests
```bash
cd web
npm test
```
*(Passes 24/24 unit test suites across Master Gateway, 8 Microservices, 5 Enterprise Contracts, and Virtual Office Telemetry)*
